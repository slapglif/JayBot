Generated by `rigorous_stat_audit.py` from existing JayBot crash-grid and falsification artifacts.

## Bottom line

The frozen synthetic option strategy **does not pass** the stricter statistical gates added here.

- CSCV/PBO approximation on the recorded 300-cell crash grid: **PBO = 66.7%**; held-out crash folds profitable: **0/3**.
- Block-bootstrap maximum-statistic correction over crash blocks: corrected **p = 1.0** for the observed best grid profit.
- Parameter-selection instability: leave-one-crash-out selection chose **3 unique parameter sets across 3 folds**.
- Purged walk-forward approximation with an 84-day embargo over annual unseen-universe blocks: profitable folds **3/5 (60%)**; largest fold supplied **64.2%** of total profit.

These results reinforce the earlier `docs/FALSIFICATION_AUDIT.md` finding that JayBot is a synthetic research signal, not a statistically validated deployable options strategy.

## Method limitations

This audit is intentionally explicit about limitations:

1. All option P&L remains synthetic Black-Scholes pricing over adjusted underlying OHLC. There is still no historical option-chain/NBBO validation.
2. The 300-cell crash grid understates the true human research family, so multiplicity remains understated.
3. CSCV/PBO and the max-stat bootstrap have only three recorded crash regimes; results are low-power approximations, not a definitive SPA/White Reality Check.
4. Walk-forward uses the existing annual frozen-rule falsification artifact; annual blocks are coarser than exact trade-level purging and it is not a pristine prospective holdout.
